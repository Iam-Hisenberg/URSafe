🤝 URSafe Volunteer Dashboard - Integration Guide

Status: ✅ Ready to Use

📋 Quick Summary

A complete volunteer management dashboard with 6 integrated tabs for disaster relief coordination:

🏕️ Camp Setup

Volunteers enter camp details, type, capacity, and resources

👥 Connect

Message & call other volunteers with modal confirmation

⚠️ Grievances

View citizen emergencies & requests (highlighted alerts)

💬 Community

Share updates with visibility controls (everyone/volunteers/government/citizens)

📋 History

Complete activity log of all volunteer actions

👤 Profile

Account info, stats, settings, and logout

✨ Key Features Implemented

✅ Messaging System

How it works: When a volunteer clicks "💬 Message" on another volunteer:
  • Chat window pops up in bottom-right corner
  • Real-time message display
  • Close button to dismiss
  • Multiple chat windows can be open simultaneously

✅ Call Function

How it works: When a volunteer clicks "📞 Call":
  • Confirmation modal appears with phone number
  • Message: "Are you sure you want to call [Name] at [Number]?"
  • Two buttons: "Call" (green) or "Cancel"
  • Clicking Call logs activity and shows toast notification

✅ Grievance Highlighting

Critical grievances are automatically highlighted with:

  • Red left border (visual indicator)
  • Background tint
  • Pulsing warning emoji (⚠️)
  • Easy access to respond via message

✅ Community Visibility Controls

When posting to community, volunteers can choose who sees their message:

  • 👥 Everyone - Citizens, Volunteers, Government
  • 🤝 Volunteers Only - Internal coordination
  • 🏛️ Government Only - Official communication
  • 👫 Citizens Only - Public information

🚀 How to Use

1. Access the Dashboard

Open in browser: volunteer-dashboard.html

2. Redirect from Login

When user selects "Volunteer" role in login, redirect to the dashboard:

// In your login form handling if (userRole === 'volunteer') { window.location.href = 'volunteer-dashboard.html'; }

3. Data Persistence

Dashboard reads/writes to localStorage with keys:

  • ursafe_user - User profile (shared with main app)
  • volunteer_camp - Camp setup information

🔌 Integration with Main App

The dashboard is designed to work standalone but integrates with your main URSafe app through:
  • Shared localStorage - Uses same user data structure
  • Same styling - Matches your app's dark theme
  • Consistent navigation - Similar UI patterns and bottom nav
  • Easy redirect - Simple role-based routing from login

📞 Live Features Demo

Sending a Message

  1. Go to Connect tab
  2. Click 💬 Message on any volunteer
  3. Chat window opens at bottom-right
  4. Type message and click 📤
  5. Message appears in conversation

Making a Call

  1. Go to Connect tab
  2. Click 📞 Call on any volunteer
  3. Modal appears: "Are you sure you want to call [Name] at [Number]?"
  4. Click Call (green) to confirm
  5. Toast shows: "📞 Calling [Name]..."
  6. Activity logged in History

Responding to Grievances

  1. Go to Grievances tab
  2. Critical items highlighted in red
  3. Click 💬 Respond to message the person
  4. Or click 📍 View Location (for production)

Sharing Community Updates

  1. Go to Community tab
  2. Type your message in the text area
  3. Choose visibility: Everyone / Volunteers / Government / Citizens
  4. Click 📤 Post
  5. Your post appears at top of feed

❓ FAQ

Q: Can multiple volunteers chat at the same time?
A: Yes! Multiple message windows can be open simultaneously. Each chat is independent.
Q: Will messages persist after refresh?
A: Not in the current version (session-only). For production, connect to a database.
Q: Can I customize the camp types?
A: Yes! Edit the select options in the Camp Setup form. Add as many as you need.
Q: How do grievances get added?
A: Currently mock data. In production, citizens submit through main app → API → dashboard.
Q: Is calling actually functional?
A: Currently shows confirmation modal and logs activity. For real calling, integrate Twilio or WebRTC.
